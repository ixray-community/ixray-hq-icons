# HQ Icons for IX-Ray Platform

Addon with high-quality redesigned in-game item icons

## Overview

This addon completely reworks all in-game item icons from scratch. All renders were remade at 2x higher resolution for improved detail. AI upscaling was selectively used only for artifacts. The result is significantly sharper and more visually pleasing icons across all game interfaces.

## Requirements

Installation:

1. Install original Stalker Call of Pripyat 1.6.02
2. Install current version of IX-Ray (minimum 1.2.1)
3. In root folder of the game create a folder `ixr_addons`
4. Extract addon archive into the game folder
5. Start the game and play

Link to the current __IX-Ray__ [release](https://github.com/ixray-team/ixray-1.6-stcop/releases/latest)

## Обзор

Этот аддон полностью перерабатывает все внутриигровые иконки предметов. Все рендеры были созданы с нуля с удвоенным разрешением для улучшенной детализации. Для артефактов использовалось дополнительное улучшение через ИИ-апскейлинг. Результат - значительно более четкие и визуально приятные иконки во всех интерфейсах игры.
